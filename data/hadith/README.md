# Unreviewed local-preview HadeethEnc snapshot

This versioned JSON is for the isolated local reader preview only. Automated source-fidelity validation is complete; scholarly accuracy, source-policy and publication approval are **not** complete. Do not publish or describe this corpus as approved.

The source content is owned by its publisher and is excluded from any code licence covering this repository. See [source policy and refresh runbook](../../docs/hadith-source-policy.md).

`manifest.json` retains edition versions, complete original notices, source/check/download URLs, publisher timestamps (as supplied, without an inferred timezone), SHA256 and retrieval timestamps. Locale directories contain one document per exported ID, including all raw source columns. English/Turkish Arabic blocks come from their own workbook, not the standalone Arabic edition. `index.json` holds compact summaries and root-topic membership; `import-report.json` records taxonomy gaps. No text is fetched at runtime.

Initial import: English 2,328 (v1.25.0), Turkish 2,150 (v1.68.0), Arabic 3,582 (v1.7.0). Eight Arabic exports have no root-topic membership and remain in All. Original XLSX and API responses are retained only in ignored local import scratch, never edited.
